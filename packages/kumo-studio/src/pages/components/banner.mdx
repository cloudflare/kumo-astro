<ComponentSection>

## Usage

```astro
---
import Banner from "@cloudflare/kumo-astro/components/banner";
import Icon from "~/components/docs/Icon.astro";
---

<Banner title="Update available" description="A new version is ready to install.">
  <Icon slot="icon" name="info" weight="fill" />
</Banner>
```

<p>
  Icons are passed via the named <code>icon</code> slot. Actions (buttons) are passed via
  the named <code>action</code> slot. For freeform content, use the default slot — this is
  used when neither <code>title</code> nor <code>description</code> are provided.
</p>

</ComponentSection>
