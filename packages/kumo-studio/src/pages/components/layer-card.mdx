## Usage

### Simple Surface

<p>Without the <code>layered</code> prop, <code>LayerCard</code> renders as a simple elevated surface card.</p>

```astro
---
import LayerCard from "@cloudflare/kumo-astro/components/layer-card";
---

<LayerCard class="p-4">
  <p>Card content</p>
</LayerCard>
```

### Layered Layout

<p>With <code>layered</code>, compose with <code>LayerCardSecondary</code> and <code>LayerCardPrimary</code> for a two-section card.</p>

```astro
---
import LayerCard from "@cloudflare/kumo-astro/components/layer-card";
import LayerCardPrimary from "@cloudflare/kumo-astro/components/layer-card-primary";
import LayerCardSecondary from "@cloudflare/kumo-astro/components/layer-card-secondary";
---

<LayerCard layered>
  <LayerCardSecondary>Header label</LayerCardSecondary>
  <LayerCardPrimary>Primary content</LayerCardPrimary>
</LayerCard>
```

### LayerCardSecondary

<p>The secondary header area — typically used for a label, step indicator, or category tag. Accepts <code>class</code> and any div attributes.</p>

### LayerCardPrimary

<p>The primary content area — the main body of the layered card. Accepts <code>class</code> and any div attributes.</p>
