## Usage

```astro

import SkeletonLine from "@cloudflare/kumo-astro/components/skeleton-line";
---

<SkeletonLine />
```

<p>
  Width, shimmer duration, and delay are randomized per render to create a
  natural staggered appearance when multiple lines are used together.
</p>

<ComponentSection>

## Custom Widths

<p>Control the randomized width range for more natural-looking skeletons.</p>

<ComponentExample
  code={`<div class="flex flex-col gap-2 w-64">\n  <SkeletonLine minWidth={80} maxWidth={100} />\n  <SkeletonLine minWidth={60} maxWidth={80} />\n  <SkeletonLine minWidth={40} maxWidth={60} />\n</div>`}
  lang="astro"
>
  <div class="flex flex-col gap-2 w-64">
    <SkeletonLine minWidth={80} maxWidth={100} />
    <SkeletonLine minWidth={60} maxWidth={80} />
    <SkeletonLine minWidth={40} maxWidth={60} />
  </div>
</ComponentExample>

## Custom Height

<p>Override the default height using the <code>class</code> prop.</p>

<ComponentExample
  code={`<SkeletonLine class="h-4" />`}
  lang="astro"
>
  <div class="w-64 flex flex-col gap-3">
    <SkeletonLine />
    <SkeletonLine class="h-4" />
    <SkeletonLine class="h-8 rounded-lg" />
  </div>
</ComponentExample>

## Block Height

<p>
  Use <code>blockHeight</code> to set the height of a container that vertically centers the skeleton line.
  Useful when replacing text of a known line height. Accepts a number (treated as <code>px</code>) or any CSS string.
</p>

<ComponentExample
  code={`<SkeletonLine blockHeight={24} />`}
  lang="astro"
>
  <div class="w-64 flex flex-col gap-2">
    <SkeletonLine blockHeight={20} />
    <SkeletonLine blockHeight={24} />
    <SkeletonLine blockHeight={32} />
  </div>
</ComponentExample>

## Card Loading State

<p>Use skeleton lines to create loading states for cards and content areas.</p>

<ComponentExample
  code={`<div class="rounded-lg border border-kumo-hairline bg-kumo-base p-4 w-64">\n  <SkeletonLine blockHeight={20} minWidth={60} maxWidth={80} />\n  <div class="mt-3 flex flex-col gap-2">\n    <SkeletonLine />\n    <SkeletonLine />\n    <SkeletonLine minWidth={40} maxWidth={60} />\n  </div>\n</div>`}
  lang="astro"
>
  <div class="rounded-lg border border-kumo-hairline bg-kumo-base p-4 w-64">
    <SkeletonLine blockHeight={20} minWidth={60} maxWidth={80} />
    <div class="mt-3 flex flex-col gap-2">
      <SkeletonLine />
      <SkeletonLine />
      <SkeletonLine minWidth={40} maxWidth={60} />
    </div>
  </div>
</ComponentExample>
