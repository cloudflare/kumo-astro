## Usage

```astro
---
import Switch from "@cloudflare/kumo-astro/components/switch";
---

<Switch label="Dark mode" />
```

<p>
  The Astro <code>Switch</code> is interactive via an inline script — no <code>client:</code> directive needed.
  It uses a hidden <code>&lt;input type="checkbox"&gt;</code> for form submission and a styled <code>&lt;button role="switch"&gt;</code>
  for the visual toggle. There is no <code>onCheckedChange</code> prop — use native <code>oninput</code>
  on the hidden input via HTML attributes if you need to respond to changes.
</p>

</ComponentSection>
