## Usage

### With Form Components (Recommended)

<p>
  Label features are automatically available through form components like <code>Input</code>, <code>Select</code>,
  <code>Checkbox</code>, and <code>Switch</code> via their <code>label</code> and <code>required</code> props.
</p>

```astro
---
import Input from "@cloudflare/kumo-astro/components/input";
---

<!-- Optional field with "(optional)" text -->
<Input label="Phone" required={false} placeholder="+1 555-0000" />
```

### Standalone Label

<p>For custom form layouts, use the <code>Label</code> component directly with a <code>for</code> attribute.</p>

```astro
---
import Label from "@cloudflare/kumo-astro/components/label";
---

<Label for="username">Username</Label>
<input id="username" type="text" />
```

## Design Guidelines

### When to Use Optional Indicators

- Use "(optional)" for optional fields when most fields in the form are required
- Be consistent within a form
- Fields with no indicator are assumed required by users

### Accessibility

- The `for` attribute links the label to its control for screen readers
- Optional indicators are purely visual — use the `required` attribute for validation
