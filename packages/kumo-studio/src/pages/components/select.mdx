## Usage

```astro
---
import Select from "@cloudflare/kumo-astro/components/select";
---

<Select
  name="fruit"
  placeholder="Choose a fruit…"
  items={[
    { label: "Apple", value: "apple" },
    { label: "Banana", value: "banana" },
  ]}
/>
```

<p>
  The Astro <code>Select</code> differs from the React version in one key way:
  options are always passed as an <strong>array of <code>{`{ label, value }`}</code> objects</strong>
  via the <code>items</code> prop. There are no <code>&lt;Select.Option&gt;</code>,
  <code>&lt;Select.Group&gt;</code>, or <code>&lt;Select.Separator&gt;</code> sub-components.
  Grouping and disabled options are handled via the <code>items</code> array.
</p>

</ComponentSection>
