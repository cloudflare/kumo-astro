<ComponentSection>

## Usage

```astro
---
import Radio from "@cloudflare/kumo-astro/components/radio";
import RadioGroup from "@cloudflare/kumo-astro/components/radio-group";
---

<RadioGroup legend="Notification preference" name="notif">
  <Radio label="Email" value="email" name="notif" />
  <Radio label="SMS" value="sms" name="notif" />
</RadioGroup>
```

<p>
  In Astro, there is no React context to propagate the <code>name</code> prop from
  <code>RadioGroup</code> to its children. Each <code>Radio</code> must have a matching
  <code>name</code> prop set explicitly.
</p>

</ComponentSection>
