## Usage

### With Built-in Field (Recommended)

<p>Use the <code>label</code> prop to enable the built-in Field wrapper with label, description, and error support.</p>

```astro
---
import Input from "@cloudflare/kumo-astro/components/input";
---

<Input label="Email" placeholder="you@example.com" />
```

### Bare Input

<p>For custom layouts, omit <code>label</code> and provide <code>aria-label</code> for accessibility.</p>

```astro
<Input placeholder="Search..." aria-label="Search products" />
```
