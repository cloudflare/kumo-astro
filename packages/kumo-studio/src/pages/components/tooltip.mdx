<ComponentSection>

## Usage

```astro
---
import Tooltip from "@cloudflare/kumo-astro/components/tooltip";
import Button from "@cloudflare/kumo-astro/components/button";
---

<Tooltip content="Save changes">
  <Button>Save</Button>
</Tooltip>
```

<p>
  The trigger element goes in the default slot. The tooltip text is passed via the required <code>content</code> prop — it accepts a plain string only (not markup). There is no <code>open</code>/<code>defaultOpen</code>/<code>onOpenChange</code> — the tooltip is always uncontrolled.
</p>

</ComponentSection>
