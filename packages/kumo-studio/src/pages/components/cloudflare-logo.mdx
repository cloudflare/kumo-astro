## Examples

### Glyph Only

<p>Use <code>variant="glyph"</code> to display just the cloud icon without the wordmark.</p>

<ComponentExample
  code={`<CloudflareLogo variant="glyph" class="w-8" />`}
  lang="astro"
>
  <CloudflareLogo variant="glyph" class="w-8" />
</ComponentExample>

### Color Variants

<p>The logo supports three color schemes: brand colors, black, and white.</p>

<ComponentExample
  code={`<div class="flex flex-wrap items-center gap-6">\n  <CloudflareLogo color="color" class="w-36" />\n  <CloudflareLogo color="black" class="w-36" />\n  <div class="rounded bg-kumo-inverted p-2">\n    <CloudflareLogo color="white" class="w-36" />\n  </div>\n</div>`}
  lang="astro"
>
  <div class="flex flex-wrap items-center gap-6">
    <CloudflareLogo color="color" class="w-36" />
    <CloudflareLogo color="black" class="w-36" />
    <div class="rounded bg-kumo-inverted p-2">
      <CloudflareLogo color="white" class="w-36" />
    </div>
  </div>
</ComponentExample>

### Glyph Color Variants

<ComponentExample
  code={`<div class="flex flex-wrap items-center gap-4">\n  <CloudflareLogo variant="glyph" color="color" class="w-8" />\n  <CloudflareLogo variant="glyph" color="black" class="w-8" />\n  <div class="rounded bg-kumo-inverted p-2">\n    <CloudflareLogo variant="glyph" color="white" class="w-8" />\n  </div>\n</div>`}
  lang="astro"
>
  <div class="flex flex-wrap items-center gap-4">
    <CloudflareLogo variant="glyph" color="color" class="w-8" />

    <div class="rounded bg-kumo-inverted p-2">
      <CloudflareLogo variant="glyph" color="white" class="w-8" />
    </div>
  </div>
</ComponentExample>

### Sizing

<p>Size the logo using CSS width classes. The height adjusts automatically to maintain aspect ratio.</p>

<ComponentExample
  code={`<div class="flex flex-wrap items-end gap-4">\n  <CloudflareLogo class="w-16" />\n  <CloudflareLogo class="w-24" />\n  <CloudflareLogo class="w-36" />\n  <CloudflareLogo class="w-48" />\n</div>`}
  lang="astro"
>
  <div class="flex flex-wrap items-end gap-4">
    <CloudflareLogo class="w-16" />
    <CloudflareLogo class="w-24" />
    <CloudflareLogo class="w-36" />
    <CloudflareLogo class="w-48" />
  </div>
</ComponentExample>
