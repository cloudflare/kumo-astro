## Usage

```astro
---
import Button from "@cloudflare/kumo-astro/components/button";
---

<Button variant="secondary">Click me</Button>
```

<p>
  Accepts <code>variant</code>, <code>size</code>, <code>shape</code>,{" "}
  <code>loading</code>, and <code>disabled</code> props. A few things to note:
</p>

- Use `class` instead of `className` for custom styles.
- Place content directly in the slot — there is no `children` prop.
- There is no `icon` prop — place an SVG element directly in the slot alongside your label text.
- For navigation, use a plain `<a>` element styled with `buttonVariants()` instead of `LinkButton`.
- The `title` (tooltip) prop is accepted but not yet rendered; tooltip wrapping is planned for a future release.

</ComponentSection>

### Icon Only

<p>
  For icon-only buttons, use `shape="square"` or `shape="circle"` and place
  your SVG icon in the slot.
  <strong>Always include `aria-label`</strong>
  for accessibility — without visible text, screen readers need the label to
  convey the button's purpose.
</p>
<ComponentExample
  code={`<div class="flex flex-wrap items-center gap-3">\n  <Button variant="secondary" shape="square" aria-label="Add item">\n    <!-- PlusIcon SVG -->\n  </Button>\n  <Button variant="secondary" shape="circle" aria-label="Add item">\n    <!-- PlusIcon SVG -->\n  </Button>\n</div>`}
  lang="astro"
  vrSection="icon-only"
  vrTitle="Icon Only"
>

### Link as Button

<p>
  Use a plain `<a>` element with `buttonVariants()` when the interaction should
  navigate somewhere but still look like a button. Use `Button` for in-place
  actions like submitting, opening, or toggling UI.
</p>
<ComponentExample
  code={`---\nimport { buttonVariants } from "@cloudflare/kumo/components/button";\n---\n\n<div class="flex flex-wrap items-center gap-3">\n  <a href="/components/link" class={buttonVariants({ variant: "secondary" })}>\n    Read Link docs\n  </a>\n  <a\n    href="https://developers.cloudflare.com"\n    class={buttonVariants({ variant: "ghost" })}\n    target="_blank"\n    rel="noopener noreferrer"\n  >\n    <!-- ArrowSquareOutIcon SVG -->\n    Cloudflare Docs\n  </a>\n</div>`}
  lang="astro"
  vrSection="link-as-button"
  vrTitle="Link as Button"
>
  <div class="flex flex-wrap items-center gap-3">
    <a href="/components/link" class={buttonVariants({ variant: "secondary" })}>
      Read Link docs
    </a>
    <a
      href="https://developers.cloudflare.com"
      class={buttonVariants({ variant: "ghost" })}
      target="_blank"
      rel="noopener noreferrer"
    >
      <Icon name="arrow-square-out" />
      Cloudflare Docs
    </a>
  </div>
