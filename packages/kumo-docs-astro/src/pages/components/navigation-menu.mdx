## API Reference

### NavigationMenu

<p>Root <code>&lt;nav&gt;</code> wrapper. Accepts <code>class</code> and any nav attributes.</p>

### NavigationMenuList

<p>Renders a <code>&lt;ul&gt;</code> with flex layout. Accepts <code>class</code>.</p>

### NavigationMenuItem

<p>Renders a <code>&lt;li&gt;</code> with relative positioning. Accepts <code>class</code>.</p>

### NavigationMenuTrigger

<p>Renders a <code>&lt;button&gt;</code> with a chevron icon that toggles a dropdown. Must be paired with <code>NavigationMenuContent</code> inside a <code>NavigationMenuItem</code>.</p>

### NavigationMenuContent

<p>The dropdown panel. Must be inside <code>NavigationMenuItem</code> alongside <code>NavigationMenuTrigger</code>.</p>
