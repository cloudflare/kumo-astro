## Usage

```astro
---
import Tabs from "@cloudflare/kumo-astro/components/tabs";
---

<Tabs
  tabs={[
    { value: "account", label: "Account" },
    { value: "password", label: "Password" },
  ]}
  defaultValue="account"
/>

<div role="tabpanel" data-panel data-value="account">
  Account settings here
</div>
<div role="tabpanel" data-panel data-value="password" hidden>
  Password settings here
</div>
```

<p>
  The Astro <code>Tabs</code> component differs from the React version in an important way:
  <strong>tab panels live outside the <code>Tabs</code> component</strong> as sibling elements.
  Astro does not support dynamic slot names, so panels cannot be passed as children.
  Each panel needs <code>role="tabpanel"</code>, <code>data-panel</code>, and a <code>data-value</code>
  attribute matching the tab's <code>value</code>. The JS script wires them up automatically.
</p>

<p>
  Tabs and panels must share a common ancestor with <code>data-kumo-tabs</code>, or panels must be
  direct siblings of the <code>Tabs</code> component.
</p>
