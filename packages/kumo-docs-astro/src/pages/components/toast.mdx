## Usage

```astro
---
import Toast from "@cloudflare/kumo-astro/components/toast";
---

<!-- Place once in your layout or page -->
<Toast position="bottom-right" />

<script>
  // Call from anywhere on the page
  kumoToast({ title: "Saved!", variant: "success" });
</script>
```

<p>
  The Astro <code>Toast</code> differs significantly from the React version:
</p>

- It renders an **empty container**. All toasts are injected at runtime via `window.kumoToast()`.
- There is no React context, no `Toasty` provider, and no `useKumoToastManager` hook.
- Place the `<Toast />` component **once** in your layout or page — multiple instances on the same page are not needed.
- Call `kumoToast(options)` from any `<script>` tag, `onclick` attribute, or inline JS.

</ComponentSection>

### Custom Duration

```astro
<script>
  // Auto-dismiss after 10 seconds
  kumoToast({ title: "Long toast", duration: 10000 });

  // Persist until manually dismissed (duration: 0)
  kumoToast({ title: "Sticky toast", duration: 0 });
</script>
```
