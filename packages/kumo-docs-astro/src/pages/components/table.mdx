### TableHead / TableCell

<p>Both accept a <code>sticky</code> prop (<code>"left" | "right"</code>) to pin the column to the edge of a horizontally scrollable container. Wrap the table in an <code>overflow-x-auto</code> container when using sticky columns.</p>

### TableBody, TableFooter

<p>Semantic wrappers. Accept <code>class</code> and any standard HTML attributes.</p>
