<ComponentSection>

## Usage

```astro
---
import Collapsible from "@cloudflare/kumo-astro/components/collapsible";
import CollapsibleTrigger from "@cloudflare/kumo-astro/components/collapsible-trigger";
import CollapsiblePanel from "@cloudflare/kumo-astro/components/collapsible-panel";
---

<Collapsible>
  <CollapsibleTrigger>Show details</CollapsibleTrigger>
  <CollapsiblePanel>Hidden content</CollapsiblePanel>
</Collapsible>
```

<p>
  The component is interactive via a bundled inline script — no <code>client:</code> directive needed.
  There is no <code>onOpenChange</code> callback. Use native DOM events if you need to respond to state changes.
</p>

</ComponentSection>

### CollapsibleTrigger

<p>Renders a <code>&lt;button&gt;</code>. Accepts <code>class</code> and any button attributes. Content goes in the default slot.</p>

### CollapsiblePanel

<p>Renders a <code>&lt;div&gt;</code> that is hidden by default. Accepts <code>class</code> and any div attributes. Content goes in the default slot.</p>
