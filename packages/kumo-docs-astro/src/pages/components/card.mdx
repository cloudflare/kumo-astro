### CardHeader, CardContent, CardFooter

<p>These sub-components accept only <code>class</code> and any HTML <code>div</code> attributes. Content goes in the default slot.</p>

### CardTitle

<p>Renders an <code>&lt;h3&gt;</code> with semibold styling. Accepts <code>class</code> and any heading attributes.</p>

### CardDescription

<p>Renders a <code>&lt;p&gt;</code> with muted text styling. Accepts <code>class</code> and any paragraph attributes.</p>
