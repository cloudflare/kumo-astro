## Usage

### With Built-in Field (Recommended)

```astro
---
import InputArea from "@cloudflare/kumo-astro/components/input-area";
---

<InputArea
  label="Description"
  placeholder="Enter a description..."
  description="Provide details about your project"
/>
```

### Bare InputArea

<p>For custom layouts, omit <code>label</code> and provide <code>aria-label</code> for accessibility.</p>

```astro
<InputArea placeholder="Add notes..." aria-label="Notes" rows={3} />
```
