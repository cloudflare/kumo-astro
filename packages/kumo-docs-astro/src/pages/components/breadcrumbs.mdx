## Usage

```astro
---
import Breadcrumbs from "@cloudflare/kumo-astro/components/breadcrumbs";
import BreadcrumbsLink from "@cloudflare/kumo-astro/components/breadcrumbs-link";
import BreadcrumbsCurrent from "@cloudflare/kumo-astro/components/breadcrumbs-current";
import BreadcrumbsSeparator from "@cloudflare/kumo-astro/components/breadcrumbs-separator";
---

<Breadcrumbs>
  <BreadcrumbsLink href="/">Home</BreadcrumbsLink>
  <BreadcrumbsSeparator />
  <BreadcrumbsLink href="/settings">Settings</BreadcrumbsLink>
  <BreadcrumbsSeparator />
  <BreadcrumbsCurrent>Profile</BreadcrumbsCurrent>
</Breadcrumbs>
```

<p>Supports a named <code>icon</code> slot for rendering an icon before the link text.</p>

### BreadcrumbsCurrent

<p>Marks the current page. Renders with <code>aria-current="page"</code>. Supports a named <code>icon</code> slot.</p>

### BreadcrumbsSeparator

<p>Purely visual chevron separator. No props. Always <code>aria-hidden</code>.</p>
