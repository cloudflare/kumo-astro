## Usage

```astro
---
import Code from "@cloudflare/kumo-astro/components/code";
---

<Code code={`const x = 1;`} lang="typescript" />
```

<p>
  Syntax highlighting runs at build time in Astro's SSR frontmatter using Shiki — no JavaScript is shipped to the browser and no <code>client:</code> directive is needed. The component uses <code>github-light</code> for light mode and <code>vesper</code> for dark mode, matching the rest of the docs site.
</p>

</ComponentSection>
