{/* Usage */}

<ComponentSection>

## Usage

```astro
---
import NativeSelect from "@cloudflare/kumo-astro/components/native-select";
---

<NativeSelect aria-label="Framework">
  <option value="react">React</option>
  <option value="vue">Vue</option>
</NativeSelect>
```

<p>Options are placed in the default slot using standard HTML <code>&lt;option&gt;</code> and <code>&lt;optgroup&gt;</code> elements.</p>

</ComponentSection>
