## Usage

```astro
---
import PopoverRoot from "@cloudflare/kumo-astro/components/popover-root";
import PopoverTrigger from "@cloudflare/kumo-astro/components/popover-trigger";
import PopoverContent from "@cloudflare/kumo-astro/components/popover-content";
import PopoverClose from "@cloudflare/kumo-astro/components/popover-close";
---

<PopoverRoot>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>
    <p>Popover content</p>
    <PopoverClose>Close</PopoverClose>
  </PopoverContent>
</PopoverRoot>
```

<p>
  The popover is interactive via a bundled inline script — no <code>client:</code> directive needed.
  There is no <code>open</code>/<code>defaultOpen</code>/<code>onOpenChange</code> — the popover is always uncontrolled.
</p>

</ComponentSection>

### PopoverTrigger

<p>Renders a <code>&lt;button&gt;</code> that toggles the popover. Accepts any button attributes.</p>

### PopoverContent

<p>Renders the popover panel. Accepts <code>class</code> and any div attributes. Content goes in the default slot.</p>

### PopoverClose

<p>Renders a <code>&lt;button&gt;</code> that closes the popover. Accepts any button attributes.</p>
