<ComponentSection>

## Usage

```astro
---
import Empty from "@cloudflare/kumo-astro/components/empty";
import Icon from "~/components/docs/Icon.astro";
---

<Empty
  title="No results found"
  description="Try adjusting your search."
>
  <Icon slot="icon" name="magnifying-glass" size={48} class="text-kumo-inactive" />
</Empty>
```

<p>
  The icon is passed via the named <code>icon</code> slot. Action buttons and other content
  go in the default slot and are rendered below the description and command line.
</p>

</ComponentSection>
