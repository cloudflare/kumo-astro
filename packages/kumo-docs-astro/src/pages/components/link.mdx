## Usage

```astro
---
import Link from "@cloudflare/kumo-astro/components/link";
---

<p>Read our <Link href="/docs">documentation</Link> for more details.</p>
```

<p>
  The Astro <code>Link</code> always renders a plain <code>&lt;a&gt;</code> element.
  There is no <code>LinkProvider</code> or <code>render</code> prop — Astro handles
  routing natively, so framework router integration is not needed.
</p>

</ComponentSection>

## Examples

### Inline in Paragraph

<ComponentExample
  code={`<p class="text-sm">\n  Read our <Link href="/docs">documentation</Link> for more details.\n</p>`}
  lang="astro"
>
  <p class="text-sm">
    Read our <Link href="/docs">documentation</Link> for more details.
  </p>
</ComponentExample>

### External Link

<ComponentExample
  code={`<Link href="https://developers.cloudflare.com" target="_blank" rel="noopener noreferrer">\n  Cloudflare Docs\n</Link>`}
  lang="astro"
>
  <Link href="https://developers.cloudflare.com" target="_blank" rel="noopener noreferrer">
    Cloudflare Docs
  </Link>
</ComponentExample>

### Current Variant

<p>Inherits color from its parent — useful for links within colored contexts like alerts.</p>

<ComponentExample
  code={`<p class="text-kumo-error text-sm">\n  An error occurred. <Link href="/help" variant="current">Get help</Link>\n</p>`}
  lang="astro"
>
  <p class="text-kumo-error text-sm">
    An error occurred. <Link href="/help" variant="current">Get help</Link>
  </p>
</ComponentExample>

### Plain Variant

<ComponentExample
  code={`<Link href="/settings" variant="plain">Settings</Link>`}
  lang="astro"
>
  <Link href="/settings" variant="plain">Settings</Link>
</ComponentExample>

</ComponentSection>
