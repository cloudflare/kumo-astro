<ComponentSection>

## Usage

```astro
---
import DropdownMenu from "@cloudflare/kumo-astro/components/dropdown-menu";
import DropdownMenuTrigger from "@cloudflare/kumo-astro/components/dropdown-menu-trigger";
import DropdownMenuContent from "@cloudflare/kumo-astro/components/dropdown-menu-content";
import DropdownMenuItem from "@cloudflare/kumo-astro/components/dropdown-menu-item";
import DropdownMenuSeparator from "@cloudflare/kumo-astro/components/dropdown-menu-separator";
---

<DropdownMenu>
  <DropdownMenuTrigger>Actions</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Edit</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="danger">Delete</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

<p>
  The dropdown is interactive via a bundled inline script — no <code>client:</code> directive needed.
  There are no <code>onClick</code> props on menu items — use native <code>onclick</code> HTML attributes
  or standard anchor <code>&lt;a&gt;</code> tags inside items for navigation.
</p>

</ComponentSection>

### DropdownMenuTrigger

<p>Renders a <code>&lt;button&gt;</code>. Accepts <code>class</code> and any button attributes. Content goes in the default slot.</p>

### DropdownMenuContent

<p>Renders the menu panel with <code>role="menu"</code>. Accepts <code>class</code> and any div attributes.</p>
