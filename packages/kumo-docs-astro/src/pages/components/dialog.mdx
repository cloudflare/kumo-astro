## Usage

```astro
---
import DialogRoot from "@cloudflare/kumo-astro/components/dialog-root";
import Dialog from "@cloudflare/kumo-astro/components/dialog";
import DialogBackdrop from "@cloudflare/kumo-astro/components/dialog-backdrop";
import DialogTrigger from "@cloudflare/kumo-astro/components/dialog-trigger";
import DialogClose from "@cloudflare/kumo-astro/components/dialog-close";
import DialogTitle from "@cloudflare/kumo-astro/components/dialog-title";
import DialogDescription from "@cloudflare/kumo-astro/components/dialog-description";
---

<DialogRoot>
  <DialogTrigger>Open</DialogTrigger>
  <Dialog>
    <DialogBackdrop />
    <DialogTitle>Title</DialogTitle>
    <DialogDescription>Content here.</DialogDescription>
    <DialogClose>Close</DialogClose>
  </Dialog>
</DialogRoot>
```

<p>
  The dialog is interactive via a bundled inline script — no <code>client:</code> directive needed.
  There is no <code>open</code>/<code>defaultOpen</code>/<code>onOpenChange</code>. The dialog is always uncontrolled.
</p>

### DialogTrigger

<p>Renders a <code>&lt;button&gt;</code> that opens the dialog. Accepts any button attributes.</p>

### DialogBackdrop

<p>The translucent backdrop. Place as first child of <code>Dialog</code>. For <code>role="dialog"</code>, clicking the backdrop closes the dialog. For <code>role="alertdialog"</code> it does not.</p>

### DialogClose

<p>Renders a <code>&lt;button&gt;</code> that closes the dialog. Accepts any button attributes. Wrap your styled button in the slot.</p>

### DialogTitle

<p>Renders an <code>&lt;h2&gt;</code>. Auto-wired to the dialog's <code>aria-labelledby</code>.</p>

### DialogDescription

<p>Renders a <code>&lt;p&gt;</code>. Auto-wired to the dialog's <code>aria-describedby</code>.</p>
