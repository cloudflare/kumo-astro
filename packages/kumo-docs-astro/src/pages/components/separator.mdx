### Semantic (Non-decorative)

<p>By default, the separator is decorative (<code>aria-hidden</code>). Set <code>decorative={false}</code> to render it with <code>role="separator"</code> for assistive technologies.</p>

<ComponentExample
  code={`<div class="flex flex-col gap-4">\n  <p class="text-kumo-default">Section A</p>\n  <Separator decorative={false} />\n  <p class="text-kumo-default">Section B</p>\n</div>`}
  lang="astro"
>
  <div class="flex flex-col gap-4">
    <p class="text-kumo-default">Section A</p>
    <Separator decorative={false} />
    <p class="text-kumo-default">Section B</p>
  </div>
</ComponentExample>
