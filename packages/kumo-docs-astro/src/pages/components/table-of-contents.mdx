## Usage

```astro
---
import TableOfContents from "@cloudflare/kumo-astro/components/table-of-contents";
import TableOfContentsList from "@cloudflare/kumo-astro/components/table-of-contents-list";
import TableOfContentsItem from "@cloudflare/kumo-astro/components/table-of-contents-item";
import TableOfContentsTitle from "@cloudflare/kumo-astro/components/table-of-contents-title";
---

<TableOfContents>
  <TableOfContentsTitle>On this page</TableOfContentsTitle>
  <TableOfContentsList>
    <TableOfContentsItem href="#intro" active>Introduction</TableOfContentsItem>
    <TableOfContentsItem href="#api">API Reference</TableOfContentsItem>
  </TableOfContentsList>
</TableOfContents>
```

<p>
  This component is purely presentational. To automatically track the active section as the user scrolls,
  enable <code>scrollSpy</code> on <code>TableOfContents</code> and add <code>data-toc-target="heading-id"</code>
  to each <code>TableOfContentsItem</code>.
</p>

### With Scroll Spy

```astro
<TableOfContents scrollSpy>
  <TableOfContentsList>
    <TableOfContentsItem href="#intro" data-toc-target="intro">
      Introduction
    </TableOfContentsItem>
    <TableOfContentsItem href="#api" data-toc-target="api">
      API Reference
    </TableOfContentsItem>
  </TableOfContentsList>
</TableOfContents>
```

<p>Renders a small uppercase <code>&lt;p&gt;</code> heading. Optional.</p>

### TableOfContentsList

<p>Renders a <code>&lt;ul&gt;</code> with a left border rail. Accepts <code>class</code>.</p>
