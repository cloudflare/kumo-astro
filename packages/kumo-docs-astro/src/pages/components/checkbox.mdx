## Usage

```astro
---
import Checkbox from "@cloudflare/kumo-astro/components/checkbox";
---

<Checkbox label="Accept terms" name="terms" />
```

<p>
  The Astro <code>Checkbox</code> is fully static — no JavaScript is needed for the visual indicator.
  The custom checkmark uses a CSS sibling selector (<code>:checked + div</code>) to toggle visibility.
  There is no <code>onCheckedChange</code> prop — use native <code>oninput</code> or <code>onchange</code>
  passed via HTML attributes for interactivity.
</p>

</ComponentSection>

### Label First Layout

<p>Use <code>controlFirst={false}</code> to place the label before the checkbox.</p>

<ComponentExample
  code={`<Checkbox label="Remember me" controlFirst={false} />`}
  lang="astro"
>
  <Checkbox label="Remember me" controlFirst={false} />
</ComponentExample>

<p>Set <code>required={false}</code> (explicit false) to append an "(optional)" indicator to the label.</p>
