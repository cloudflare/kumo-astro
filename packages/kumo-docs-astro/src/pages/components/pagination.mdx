## Usage

```astro
---
import Pagination from "@cloudflare/kumo-astro/components/pagination";
---

<Pagination totalItems={100} pageSize={10} />
```

<p>
  The Astro <code>Pagination</code> is interactive via a bundled inline script — no <code>client:</code> directive needed.
  State is managed in the DOM via <code>data-*</code> attributes. Listen for page changes with a custom DOM event:
</p>

```astro
<script>
  document.querySelector('[data-kumo-pagination]')
    ?.addEventListener('kumo:page-change', (e) => {
      const { page, pageSize } = e.detail;
      // fetch new data...
    });
</script>
```

<p>
  The Astro API differs from the React version: use <code>totalItems</code>/<code>pageSize</code> instead of
  <code>totalCount</code>/<code>perPage</code>, and there is no <code>setPage</code> callback or compound component API.
</p>
